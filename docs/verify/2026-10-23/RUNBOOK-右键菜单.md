# RUNBOOK：右键菜单真机眼验（S6-A2）

- **对象**：用户日常使用的真实实例与真实媒体库（`%LOCALAPPDATA%\hmp`）。
- **执行者**：用户本人（协调者转交）。预计 10-15 分钟。
- **背景**：headless 截图验收已完成 9/12 项（见 `verify/REPORT.md`）；本 runbook 覆盖
  headless 无法触达的交互面（点外关闭、ESC、滚动跟随、锚行滚出自动关、设置持久化），
  以及 **缺陷 #1 的真机确认**（headless 下已实证：弹层内任意完整点击都会关闭弹层，
  导致「加入播放列表…」二级面板不可达；本 runbook 第 8 节在真机上复核）。
- **标记约定**：【只读】不改变任何状态；【变更·可回滚】会改真库，按回滚步骤恢复。
- 软件渲染截图的已知豁免（阴影/圆角裁剪/纹理采样）在真机上应**正常呈现**，顺带核对。

---

## 0. 前置

1. 启动 `hmp-desktop`（或确认已在跑）；准备一首 QQ 在库曲目与一首本地扫描曲目。
2. 确认设置→常规中「右键菜单」开关为开（默认开）。

## 1. 曲目表右键（library 上下文）【只读】

在「我喜欢 / 音乐库 / 最近播放」任一曲目行上右键：

- [ ] 面板 216px 宽、surface 底色、圆角、**12px 阴影**（真机应有；headless 豁免项）
- [ ] 条目：播放 / 下一首播放 / 加入队列 ‖ 加入播放列表… ‖ 查看歌手 / 查看专辑
- [ ] QQ 曲：查看歌手/查看专辑可用；mid 缺失的行（如某些本地曲）：灰显不可点
- [ ] hover 行有浅色高亮 + 图标提亮；两处分隔线为 1px 细线
- [ ] 浅/暗主题各看一遍（设置→常规切换）

## 2. 关闭语义【只读】

- [ ] 点击面板外任意处 → 关闭
- [ ] 按 ESC → 关闭
- [ ] 打开菜单后滚动列表 → 面板跟随锚行移动
- [ ] 打开菜单后把锚行滚出可视区 → 面板自动关闭（窗口化虚拟化卸载行）

## 3. 队列抽屉右键（queue 上下文）【只读】

播放中打开右侧队列抽屉，在队列行上右键：

- [ ] 条目：播放 / 下一首播放 / 加入队列 ‖ **从队列移除**（无「加入播放列表…」）‖ 查看歌手/查看专辑
- [ ] 面板在抽屉内右缘被水平钳制，不越窗

## 4. 歌单详情页右键（playlist 上下文）【只读】

侧栏任一歌单 → 详情页曲目行右键：

- [ ] 条目集 = library + 「从歌单移除」（共 7 项）

## 5. 边缘几何【只读】

- [ ] 列表末行附近右键 → 面板上收钳制，底缘不越窗
- [ ] 行最右端右键（library 主区右缘 / 抽屉内）→ 水平钳制不越窗

## 6. 设置开关持久化【只读】

- [ ] 设置→常规关闭「右键菜单」→ 各页面右键无任何反应
- [ ] 重启 hmp-desktop → 保持关闭（持久化生效）→ **测完把开关恢复为开**

## 7. 未接入区无动作【只读】

- [ ] 侧栏空白、页面标题区、设置页等非曲目区右键 → 无菜单

## 8. 【重点】缺陷 #1 真机复核：二级 picker 面板【只读】

**预期缺陷表现**（headless 实证链见 REPORT 缺陷 #1）：

1. 在任一曲目行右键 → 点击「**加入播放列表…**」
2. [ ] **预期缺陷**：菜单整体关闭，**没有**出现二级歌单选择面板
   （正常应为：面板切换为「加入播放列表 / 返回 + 歌单列表」）
3. 若真机同样复现 → 缺陷 #1 在 femtovg/winit 后端成立，修复优先级评估交协调者
4. 若真机**正常显示**二级面板（与 headless 不同）→ 请记录后端差异，同样上报

> 根因（供修复参考，S6 不修）：`ui/track-table.slint` 与 `ui/queue-drawer.slint` 的
> `row-menu := PopupWindow` 未设 `close-policy`，slint 默认 `close-on-click`
> （弹层内完整点击即关闭）。「加入播放列表…」行的 `activated` 只切 `picker-mode`
> 不调用 `dismissed`，框架随即关闭弹层。其余条目因显式 `dismissed()` 症状被掩盖。
> 修复方向：两处宿主补 `close-policy: close-on-click-outside;`

## 9. 二级 picker 面板细节（**仅当第 8 节真机正常显示时执行**；否则缺陷修复后补验）

- [ ] 返回行「加入播放列表」可回到主模式
- [ ] owned 歌单行对本地曲灰显 +「不支持本地曲」尾注；纯本地歌单可点
- [ ] 自建歌单 >6 个时列表内滚动
- [ ] 无自建歌单时空态「还没有自建歌单」（64px 高）

## 10.【变更·可回滚】动作链冒烟（可选，跳过不影响验收）

仅当需要验证动作真实生效：

1. 建**一次性测试歌单**（名字前缀 `s6-眼验-`）
2. 曲目右键 → 加入播放列表…（若缺陷 #1 未复现）或用行内按钮替代 → 加入该歌单 → 打开歌单核对
3. 队列抽屉：右键「从队列移除」→ 行消失
4. **回滚**：删除 `s6-眼验-` 歌单；被移除的队列行重新 queue add 即可
