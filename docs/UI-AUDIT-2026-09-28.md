范围：crates/hmp-desktop（Slint 桌面端）全部 17 路由 + 播放页 overlay + 队列抽屉 + 播放条 + 自绘标题栏。

## 二、P0（功能失效）

- **N1** ✅ 播放页收起键点击无效（= U1）。修法：collapse-touch 块移到 VerticalLayout 之后（slide 内最后声明 = 最顶层）；配合 S2 沉浸化把收起键 y 下移至 `title-bar-height + space-2`（避开 TitleBar 命中带）。
- **N4** ✅ 歌词「加载中…」是死分支：空态条件 `lyrics.length == 0 && !lyrics-loading`（now-playing.slint:544）排除加载态，内层三元 loading 支永假，加载期整列白屏。修法：去掉 `&& !NowPlaying.lyrics-loading`。

## 三、P1（明显不合理）

### 壳层 / 交互横切
- **S2** ✅ overlay 非沉浸（= U2）。修法：NowPlayingOverlay 挂载改 `y:0; height:parent.height`；TitleBar 保持最后声明（z 序最高，窗口钮/拖拽始终可用）；标题文字「胡桃音乐」在 overlay 打开时隐藏（TitleBar 加 immersive 入参）；收起键 y 下移见 N1。QueueDrawer 遮罩同步全屏，内部面板/关闭键几何 +title-bar-height 补偿。
- **S3** ✅ 侧栏收起态（64px）页脚三按钮横排需 140px，被裁不可见不可点（sidebar.slint:351-394）；Vue 收起态为竖排。修法：collapsed 分支改竖排。
- **S4** ✅ 操作反馈条 z 序低于 overlay/抽屉：播放页开着时「离线/命令被拒」提示完全不可见（app.slint:204-224 声明序在两层之前）。修法：移到 QueueDrawer 之后声明。
- **S6** ✅ ESC 次序：overlay+抽屉同开时一次 ESC 只关 overlay，抽屉 themed 态跳变（app.slint:263-277）；Vue 一次全关。修法：两层同开时一并关闭。

### 播放页
- **N2** ✅ 刻度进度条（= U3）：删 864-879 两个 for 块；顺修静息条偏心（845 行 `y:(parent.height-6px)/2` → `(parent.height-self.height)/2`）；注释与文件头措辞、DESIGN.md:20/98-100 同步。
- **N7** ✅ 控制台缺两端时间标签（Vue RulerProgress 有 elapsed/-remaining，DESIGN.md:102）。修法：Player global 加 `elapsed-text/remaining-text`（已由主代理铺好 stores.slint + player_bridge.rs 推送链），ruler 行两端消费。
- **N6** ✅ 控制台 116px 定高内容仅 94px，按钮排悬空底边偏重（now-playing.slint:811,829-833）。修法：收紧至 ~104px 并复核 QueueDrawer 底边联动。

### 详情 / 搜索
- **D1** ✅ 侧栏歌单行渲染成可点样式但无 clicked——PlaylistCover 数据无 id 字段，Rust `sidebar_cover` 只填名字色对（sidebar.slint:227-253,323-343；data.slint；bridge.rs:53-71）。修法：PlaylistCover 加 id、两处 HoverItem 补 `Nav.navigate(Route.playlist, id)`、bridge 填 id。
- **D3** ✅ 搜索并发乱序覆盖：`Data.on_search` 无代守卫，先发后至会拿旧结果盖新关键词（bridge.rs:821-853；app.rs:630-648 有先例）。修法：照 NetworkRequestState 加代计数。

### 在线页 / 设置
- **E1** ✅ 发现页遗留调试占位：state 0/1 渲染白色 `LOADING BLOCK` 文字（discover-page.slint:47-58），浅底不可见、文案是调试用语。修法：改 muted「正在加载…」居中块。

- **T1** ✅ 排行榜卡单行排布同病：TopCard 固定 280px，一组 4 卡即 1168px > 内容区，右侧卡不可达（top-page.slint:153-162）。修法：按容器宽算列数换行（CoverCardGrid 模式）。
- **T2** ✅ 榜单详情标题下孤立「·」：meta-items 恒传两元素，found=false 时均为空串，PageHeader 对 index>0 无条件渲染分隔符（top-detail-page.slint:27-31 + page-parts.slint:85-90），还把页头撑高 20px。修法：PageHeader 分隔符与文本都包 `if item != ""`。
- **T3** ✅ 账号页「重进此页刷新」承诺不兑现：AccountStatus 只在 bind() 查一次，on_navigate 不覆盖 SettingsAccount（bridge.rs:862-886,691-706）。修法：进页重发 AccountStatus。
- **T6** ✅ 榜单详情换榜残留：装载只置 state=1，旧榜名/旧 found 留存；meta 用 daemon total（300）而表只拉 100 行（top-detail-page.slint:22,27-31；bridge.rs:226-234）。修法：装载前置 found=false；meta 条数改用 tracks.length。
- **D5** ✅ 搜索结果表搜索中闪没（state==1 整块卸载；search-page.slint:95-102,128）；空关键词回车残留旧结果（search-page.slint:61-67）。修法：state==1 保持表格挂载；空关键词重置 state=0。

### 播放条 / 音量

## 五、本轮不修（记录在案）
